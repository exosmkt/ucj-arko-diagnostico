# Arko Diagnóstico
Análise financeira PF × PJ com IA — desafio UCJ (caso Dra. Carla).
Pipeline de 2 passos (diagnóstico + auditoria) com validação determinística dos números.
Modelo principal: Gemma-4 (OpenRouter, gratuito) · fallback: Gemini 2.5 Flash.
Stack: Node + Express, extração de PDF via poppler. Deploy: Docker/Coolify.
Veja MAKING_OF.md para a engenharia completa.
